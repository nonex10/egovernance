SETUP (XAMPP/WAMP)
1. Copy the folder egov_broadcast into htdocs.
2. Start Apache + MySQL, open phpMyAdmin, import schema.sql.
3. Edit config/db.php if your MySQL user/password differ.
4. Citizen dashboard : http://localhost/egov_broadcast/
   Admin dashboard   : http://localhost/egov_broadcast/admin/login.php
   Login: admin / admin123
